# ServerMaster for macOS

The native SwiftUI application, its tests, and the Xcode project live here.

Open `ServerMaster.xcodeproj` in Xcode. The Release configuration builds a
universal application for Apple Silicon and Intel Macs and targets macOS 14 or
newer.

Version 1.0 uses build identifier `arm.27.0.b6.uni`. Release binaries are published through
GitHub Releases rather than committed to the repository.
